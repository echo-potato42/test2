# Kanban TODO

自分用のタスク管理ツール。カンバン方式のボードでタスクの状態を視覚的に管理できる。

## 特徴

- **3カラムのカンバンボード** — TODO / 作業中 / 完了 でタスクを管理
- **WIP制限** — 「作業中」に置けるタスクは1つだけ。今やるべきことに集中できる
- **親子タスク** — 親タスクはカンバン上部に進捗バーで表示。子タスクが独立してカンバンのカラムを移動する。全子タスクが完了すると親タスクも自動完了
- **カウントダウンタイマー** — カード内に埋め込み表示。所要時間を設定し手動で開始。作業中→TODOに戻しても残り時間を保持して再開可能
- **突発タスク中断** — 割り込みが入ったら中断時間（分）を入力してタイマーを一時停止。指定時間後に自動再開
- **タグ** — 自由にタグを作成してタスクを分類
- **ドラッグ&ドロップ** — カード をドラッグしてカラム間を移動（矢印ボタンでも移動可）
- **データ永続化** — localStorage に自動保存。ブラウザをリロードしてもデータとタイマーが復帰する
- **ダークモード** — 目に優しいダークテーマ
- **レスポンシブ** — スマホでは縦積みレイアウトに切り替わる
- **依存ゼロ** — フレームワークなし。Vanilla JavaScript のみで構築

## インストール

```bash
git clone <repository-url>
cd test2
npm install
```

## 使い方

### 開発サーバーの起動

```bash
npm run dev
```

表示されたURL（通常 `http://localhost:5173`）をブラウザで開く。

### 本番用ビルド

```bash
npm run build
npm run preview   # ビルド結果をローカルで確認
```

`dist/` フォルダに静的ファイルが生成される。任意のWebサーバーで配信可能。

## 操作方法

### タスクの追加

1. 右上の **「+ New Task」** ボタンをクリック
2. タイトル、所要時間（任意）、タグ（任意）を入力
3. 「Add」で追加。TODO カラムに表示される

### サブタスクの追加

- **新規タスク作成時**: フォームの「Parent task」ドロップダウンから親を選択
- **親タスクの概要カードから**: カンバン上部の親カードにある **「+ Sub」** ボタンをクリック
- サブタスクを追加すると、親タスクはカンバンから上部の概要エリアに移動する

### タスクの移動

- **ドラッグ&ドロップ**: カードを掴んで別のカラムにドロップ
- **矢印ボタン**: カード下部の ← → ボタンで移動

### タイマーの使い方

1. タスクに所要時間を設定して「作業中」カラムに移動
2. カード内に表示される **「Start Timer」** ボタンを押す
3. カード内にカウントダウンが表示される（残り時間で緑→黄→赤に変化）
4. 終了時にブラウザ通知が届く

**タイマーの一時停止と再開:**
- 作業中→TODOに戻しても残り時間は保持される
- 再度「作業中」に移動すると **「Resume Timer (残り時間)」** ボタンで途中から再開できる
- **「Reset」** ボタンで残り時間をリセットしてやり直しも可能

### 突発タスクで中断する場合

1. カード内の **「Interrupt」** ボタンを押す
2. 中断にかかる時間（分）を入力して「OK」
3. タイマーが一時停止し、指定時間後に自動再開
4. すぐ戻れる場合は **「Resume」** で手動再開も可能

### 親タスクと子タスク

- **親タスク**: 子タスクを持つと、カンバン上部の概要エリアに進捗バー付きで表示される
- **子タスク**: カンバンのカラムを独立して移動する。カードに「↳ 親タスク名」のラベルが表示される
- 全ての子タスクが完了すると、親タスクも自動で完了になり左側に移動する
- 子タスクを1つでも未完了に戻すと、親も未完了に戻る

### タスクの完了

- チェックボックスをクリックすると完了状態になり「Done」カラムに移動
- 完了タスクのチェックを外すと「TODO」に戻る

## 技術構成

```
src/
├── main.js                  # エントリーポイント
├── style.css                # ダークテーマ・レイアウト
├── components/              # UI描画
│   ├── board.js             # カンバンボード全体
│   ├── column.js            # 各カラム
│   ├── task-card.js         # タスクカード（タイマーUI含む）
│   ├── task-form.js         # 作成・編集モーダル
│   ├── parent-overview.js   # 親タスク概要エリア
│   ├── notification.js      # ブラウザ通知
│   └── toast.js             # トースト通知
├── state/                   # 状態管理
│   ├── store.js             # pub/subストア
│   └── actions.js           # 全ての状態操作
├── models/
│   └── task.js              # タスクデータモデル
└── utils/
    ├── storage.js           # localStorage永続化
    ├── timer.js             # カウントダウンループ
    ├── timer-resume.js      # リロード時のタイマー復帰
    ├── drag-drop.js         # ドラッグ&ドロップ
    └── id.js                # ID生成
```

- **ビルドツール**: Vite
- **フレームワーク**: なし（Vanilla JS）
- **外部依存**: なし（devDependencies に Vite のみ）
